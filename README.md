# afasuppliesllc-site

Static site for AFA Supplies LLC (afasuppliesllc.com), served by GitHub Pages from `main`.

- `index.html` front door; `supplies.html`; `interiors.html`; `about.html`; `privacy.html`; `404.html`
- Quote forms post to Formspree (endpoint in the `FORM_URL` variable in `supplies.html` and `interiors.html`)
- `robots.txt`, `sitemap.xml`, favicons and `og-image.png` handle search and sharing
